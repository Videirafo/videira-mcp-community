# Security Policy — Community Sample

Report findings privately to the repository owner or through a private GitHub security advisory. Do not publish credentials, personal data, device identifiers or sensitive production details in public issues.

This package uses synthetic values. No production OAuth, API keys, network calls, VPS, shell, remote devices, GitHub writes or deployments. It is not production-hardened.

Untrusted pull requests run only on GitHub-hosted CI, with minimal read-only token privileges and no access to production. There is no guarantee of absolute security.
